News_TEST

A modern AI-powered news aggregation and analysis platform built using NewsAPI.ai integrations, automation workflows, and intelligent content processing.

🚀 Overview

News_TEST is designed to fetch, process, analyze, and present news content from multiple sources using APIs and automation pipelines. The project focuses on scalable news intelligence workflows, category-based filtering, and AI-assisted content handling.

This repository is ideal for:

News aggregation
AI-powered news analysis
Media monitoring
Automated article workflows
API experimentation with NewsAPI.ai
Content categorization and filtering

⚙️ Installation

Clone the repository:

git clone https://github.com/Rajatpatyal/News_TEST.git

Move into the project directory:

cd News_TEST

Install dependencies:

pip install -r requirements.txt
🔑 API Configuration

Create an environment file:

touch .env

Add your API credentials:

NEWS_API_KEY=your_api_key_here
▶️ Running the Project
python main.py

Or run individual scripts:

python scripts/fetch_news.py
